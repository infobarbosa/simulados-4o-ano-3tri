# CLAUDE.md

## What this is

A static, serverless practice-exam app (HTML, CSS, vanilla JS ES modules, no build) for a 4th grader, published on GitHub Pages from `main` (root). It is a port of the private sibling repo `simulados-vitor` (FastAPI + SQLite + parents area + Pokémon artwork); here there is no server, no parents area and no third-party artwork (cards are original procedurally drawn creatures). `README.md` is the user-facing guide, in Portuguese. All UI text and code identifiers are Brazilian Portuguese; keep it that way.

The repository is **public**: never add the child's name, the source PDFs or textbook photos. The app asks for a name on first visit and stores it only on the device.

## Commands

```bash
python3 -m http.server 8000                         # run locally
# unit tests: http://localhost:8000/tests/  (tab title "OK 21/21")
python3 tests/e2e_figuras.py http://localhost:8000/ [dir]   # plays both Matemática 4 and 5: figures + painting
python3 tests/e2e.py http://localhost:8000/ [dir]   # playwright + Chrome; plays full rounds on iPhone/Pixel emulation
python3 tools/gerar_conteudo.py PASTA_DOS_PDFS      # regenerate conteudo/*.json from the PDFs (needs pdftotext)
```

## Architecture

- **`conteudo/`**: `catalogo.json` (list of simulados) plus one `<disciplina>-<prova>-<n>.json` per simulado (43, 27 questions each: vf, associacao, lacuna, multipla, and `pintar` in the two newest Matemática ones). 36 of them are generated by `tools/gerar_conteudo.py` using `tools/importador.py` (copied from `simulados-vitor`; it parses `pdftotext -layout` output). Simulado ids are stable keys for saved progress.
- **`conteudo/manuais/`**: the simulados written by hand, with no PDF behind them (Multidisciplinar 2, written for the 21/10/2026 exam: Matemática and Gramática 4 and 5, plus Gramática 6, which is only about verbs and is the first to carry `materia`/`ajuda`; and Geografia P1 4 and 5, written for the 28/10/2026 exam on Capítulo 8, which cover the two pages no generated simulado touched — the industry map on p. 83 and the workers chart on p. 87, both carried as `contexto` boxes because the publisher's images cannot go in this repo). `gerar_conteudo.py` wipes `conteudo/*.json` before regenerating, so **these live in `manuais/` and are copied out at the end of that run** — edit them there, never the copy. Their catalog entries are merged and sorted with the generated ones.
- **`tools/ajustes.py` + `tools/ajustes_contexto.json`**: content fixes applied by `gerar_conteudo.py` on top of what the PDFs give (so regenerating never undoes them). Used for questions that depended on a textbook figure/text (Frações: the pão de queijo recipe and the orange-juice rule): a `contexto` box (`{icone, titulo, itens}`) shown above the question by `quiz.js` and read aloud, and rewritten `enunciado`s. It also carries `ajuda` (the mini-lesson topic of a question) and, under the reserved key `_simulado`, the simulado-level `materia` — that is how the three generated Geografia P1 simulados got the content button without being editable directly. Never changes the gabarito; `confere` makes the import fail if the numbering shifts. A copy lives in `simulados-vitor/app/simulados_app/`. It was kept identical until 21/10/2026, when `ajuda`/`_simulado` were added here only: they serve the content button, which the private app does not have, and that app is being archived. The copy there still runs — its own JSON uses none of the new fields. Never put textbook images in this public repo (publisher copyright): use text or original drawings.
- **`js/motor.js`**: pure grading/shuffle logic, a port of `correcao.py` from `simulados-vitor`. Change rules in both — **except the `pintar` type, which exists only here** (agreed with the parent on 2026-10-14: the private app has no simulado with it). If a question of that type ever reaches `simulados-vitor`, port the rule there too.
- **`js/figuras.js`**: draws the fraction figures in SVG (`barra`, `circulo`, `reta`, `colecao`, and `comparar` for two figures side by side), from a `figura` field on the question — the textbook's painted squares, pies and number lines, redrawn, never scanned. Also `descreverFigura()`, the text used for the read-aloud and the `aria-label`: a figure is never colour alone. `figuraInterativa()` is the painting version used by the `pintar` type, where the child taps the parts; a `pintar` question must ship **without** `pintadas` (that is the answer) and `motor.js` `validar()` fails if it does. A Coluna A item of an associação may also carry a `figura` (its `texto` then serves as the spoken description).
- **`conteudo/materia/`**: the mini-lessons behind the **"📖 Não sei — ler o conteúdo"** button on the question screen (and "📖 Ler o conteúdo" in the feedback of a wrong answer). One file per subject area (`gramatica-verbo.json`: the four verb topics of Cap. 27; `geografia-urbano.json`: the seven topics of Cap. 8), each with `topicos.<key>` = `{titulo, icone, pagina, blocos}`; a bloco is `texto`, `lista`, `exemplos`, `tabela` or `dica`, rendered by `blocoEl()` in `quiz.js` and read aloud by `materiaParaFalar()`. A simulado opts in with a top-level `materia` field naming the file; each question points at a topic with `ajuda`. The button is absent when either is missing, so content can be added one subject at a time. **Write the mini-lesson so it teaches the rule without answering the question in front of the child** (the verb ones use examples that appear nowhere in simulado 6); reading never changes the grade. `api.js` serves them at `/api/materia/<arquivo>/<topico>`; `tests/index.html` checks that every `ajuda` has a topic and every topic is used.
- **`js/api.js`**: the "server inside the browser". Keeps progress in `localStorage` (key `s4a3t_estado_v1`) and answers the `/api/...` calls the screens make (`catalogo`, `simulados/<id>/tentativas`, `tentativas/<id>[/respostas|/concluir]`, `album`). Also name, backup export/import and reset. `util.js` re-exports `api`.
- **`js/cartas.js`**: element per subject, rarity per grade, invented names and attacks. **`js/criatura.js`**: card and SVG creature from a seed. The grade of the round is shown on the card footer, but is **not** stored on the card: `comNota()` in `api.js` joins it from the tentativa that produced it, so cards earned before that change show it too and there is a single place where a grade is corrected.
- **`js/app.js`** (router: `#/`, `#/d/<disciplina>`, `#/album`, `#/ajustes`, `#/boas-vindas`, plus quiz/resultado routes), **`js/quiz.js`** (question player, result screen), **`js/util.js`** (`el()` DOM helper, voice, sounds, dialogs, confetti).
- **`js/termos.js`**: versioned terms-of-use text (`VERSAO_TERMOS`) and the first-visit consent block (summary + collapsed full text + checkbox). Consent is stored apart from the progress (`termosAceitos`/`aceitarTermos` in `api.js`, key `s4a3t_termos_v1`), so restoring a backup never accepts for the user and resetting progress never revokes it. New users must tick the box on the welcome screen; existing users, or anyone whose saved version is older, see an "Antes de continuar" screen once (guard at the top of the router). Changed the text? Bump `VERSAO_TERMOS` (and `DATA_TERMOS`), `VERSAO` in `sw.js`. No analytics or third-party requests exist, and the text says so: keep it true. `tests/e2e_termos.py` covers the flow.
- **`sw.js`**: stale-while-revalidate over a fixed list. **Bump `VERSAO` and keep `ARQUIVOS` in sync (including every `conteudo/*.json`) whenever files change or are added.**

## Constraints

All paths relative (site lives under a subpath). One question per screen, large touch targets, no timer, errors in orange with encouraging copy (ADHD-friendly; agreed with the parent). `prefers-reduced-motion` respected. `img/apple-touch-icon.png` must stay a PNG.
