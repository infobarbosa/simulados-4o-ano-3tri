# CLAUDE.md

## What this is

A static, serverless practice-exam app (HTML, CSS, vanilla JS ES modules, no build) for a 4th grader, published on GitHub Pages from `main` (root). It is a port of the private sibling repo `simulados-vitor` (FastAPI + SQLite + parents area + Pokémon artwork); here there is no server, no parents area and no third-party artwork (cards are original procedurally drawn creatures). `README.md` is the user-facing guide, in Portuguese. All UI text and code identifiers are Brazilian Portuguese; keep it that way.

The repository is **public**: never add the child's name, the source PDFs or textbook photos. The app asks for a name on first visit and stores it only on the device.

## Commands

```bash
python3 -m http.server 8000                         # run locally
# unit tests: http://localhost:8000/tests/  (tab title "OK 11/11")
python3 tests/e2e.py http://localhost:8000/ [dir]   # playwright + Chrome; plays full rounds on iPhone/Pixel emulation
python3 tools/gerar_conteudo.py PASTA_DOS_PDFS      # regenerate conteudo/*.json from the PDFs (needs pdftotext)
```

## Architecture

- **`conteudo/`**: `catalogo.json` (list of simulados) plus one `<disciplina>-<prova>-<n>.json` per simulado (36, 27 questions each: vf, associacao, lacuna, multipla). Generated by `tools/gerar_conteudo.py` using `tools/importador.py` (copied from `simulados-vitor`; it parses `pdftotext -layout` output). Simulado ids are stable keys for saved progress.
- **`js/motor.js`**: pure grading/shuffle logic, a port of `correcao.py` from `simulados-vitor`. Change rules in both.
- **`js/api.js`**: the "server inside the browser". Keeps progress in `localStorage` (key `s4a3t_estado_v1`) and answers the `/api/...` calls the screens make (`catalogo`, `simulados/<id>/tentativas`, `tentativas/<id>[/respostas|/concluir]`, `album`). Also name, backup export/import and reset. `util.js` re-exports `api`.
- **`js/cartas.js`**: element per subject, rarity per grade, invented names and attacks. **`js/criatura.js`**: card and SVG creature from a seed.
- **`js/app.js`** (router: `#/`, `#/d/<disciplina>`, `#/album`, `#/ajustes`, `#/boas-vindas`, plus quiz/resultado routes), **`js/quiz.js`** (question player, result screen), **`js/util.js`** (`el()` DOM helper, voice, sounds, dialogs, confetti).
- **`sw.js`**: stale-while-revalidate over a fixed list. **Bump `VERSAO` and keep `ARQUIVOS` in sync (including every `conteudo/*.json`) whenever files change or are added.**

## Constraints

All paths relative (site lives under a subpath). One question per screen, large touch targets, no timer, errors in orange with encouraging copy (ADHD-friendly; agreed with the parent). `prefers-reduced-motion` respected. `img/apple-touch-icon.png` must stay a PNG.
